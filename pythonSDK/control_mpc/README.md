# MPC平面控制器 - 解决200ms延迟问题

## 核心设计理念

**PID (反应式)**: "我看到了一个误差，我现在就根据这个误差做出反应。"（但这个误差是200ms前的）

**MPC (预测式)**: "我知道我的命令要200ms后才生效。那么，为了让无人机在未来的T秒内保持在最佳轨迹上，我现在应该发出什么命令？"

## 系统架构

```

│   系统辨识       │───▶│    MPC控制器      │───▶│   延迟补偿器     │
│ 自动学习模型     │    │ 预测+优化        │    │ 状态预测        │
└─────────────────┘    └──────────────────┘    └─────────────────┘
       │                         │                       │
       ▼                         ▼                       ▼
  学习 A,B矩阵            求解优化问题              补偿200ms延迟
```

## 运行流程

### 阶段1: 系统辨识 (12秒)
- 发送随机激励信号 (PRBS)
- 记录输入-输出数据
- 最小二乘法拟合模型
- 验证模型质量 (R² > 0.6)

### 阶段2: MPC控制
- 使用学习的模型进行预测
- 实时延迟补偿
- 50Hz控制频率
- 自动到达目标航点

## 核心算法

### 1. MPC优化问题
```
最小化: Σ ||x_k - x_ref||²_Q + ||u_k||²_R
约束:   x_{k+1} = A*x_k + B*u_k
       |u_k| ≤ max_stick
```

### 2. 延迟补偿
```
测量状态 → 前向预测 → 当前真实状态
x_real = x_measured + Σ A^i * B * u_{k-delay+i}
```

### 3. 系统辨识
```
数据: [x(k), u(k-delay)] → x(k+1)
模型: x(k+1) = A*x(k) + B*u(k-delay)
求解: θ = [A; B] = (X^T*X)^{-1} * X^T * Y
```

## 参数配置

### MPC参数
- 预测时域: N=10步 (200ms)
- 控制时域: M=5步
- 状态权重: Q = diag([100, 100, 1, 1]) (位置重要)
- 控制权重: R = diag([1, 1]) (杆量平滑)

### 系统辨识参数
- 辨识时间: 12秒
- 激励幅值: 50 (杆量单位)
- 信号类型: PRBS (伪随机二进制序列)
- 质量阈值: R² > 0.6

### 延迟补偿参数
- 预期延迟: 10步 (200ms @ 50Hz)
- 缓冲区大小: 15步 (预留余量)
- 自适应估计: 滑动窗口中位数

## 性能优势

相比传统PID:
1. **延迟鲁棒性**: 专门设计处理200ms延迟
2. **预测性**: 提前规划最优轨迹
3. **自适应**: 自动学习无人机特性
4. **多约束**: 同时处理位置、速度、控制限制

## 故障处理

### 常见问题
1. **模型辨识失败** (R² < 0.6)
   - 增加辨识时间
   - 检查激励信号幅值
   - 确认位置反馈质量

2. **MPC求解失败**
   - 检查系统模型合理性
   - 降低预测时域
   - 放宽控制约束

3. **延迟补偿异常**
   - 检查命令缓冲区
   - 验证时间同步
   - 调整延迟估计

## 扩展方向

1. **非线性MPC**: 考虑更复杂的无人机模型
2. **鲁棒MPC**: 处理模型不确定性
3. **多目标优化**: 同时优化能耗和精度
4. **自适应预测**: 在线更新模型参数

---

**核心价值**: 将200ms的通信"劣势"转化为预测控制的"优势"，让延迟成为更精确控制的基础。
