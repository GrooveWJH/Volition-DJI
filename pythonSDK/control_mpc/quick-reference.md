└───────────────────────────────────────────────────────────────────┘

  1. 遥控器开机 → 无人机开机
  2. 手动起飞到 1.0m 高度
  3. 悬停在中心位置 (0, 0)
  4. 运行: python control_mpc/mpc_main.py
  5. 等待系统辨识完成（10秒）
  6. 观察MPC控制过程

┌───────────────────────────────────────────────────────────────────┐
│ 4️⃣ 紧急情况处理（按优先级）                                         │
└───────────────────────────────────────────────────────────────────┘

  🚨 级别3 - 严重失控
      → 遥控器立即切换手动模式
      → 稳定姿态或紧急降落
      → 电脑 Ctrl+C（如来得及）

  ⚠️ 级别2 - 超调/振荡/发散
      → 立即 Ctrl+C 停止程序
      → 遥控器切换手动模式
      → 归中杆量，稳定悬停

  ⚡ 级别1 - 一般异常（小幅振荡、偏差）
      → 继续观察30秒
      → 如未改善，Ctrl+C 停止

┌───────────────────────────────────────────────────────────────────┐
│ 5️⃣ 异常信号识别                                                    │
└───────────────────────────────────────────────────────────────────┘

  ✗ 危险信号（立即手动接管）：
    • 距离持续增大（发散）
    • 向边界急速飞去
    • 突然下坠/上升
    • MPC:fail 持续出现
    • 测量位置冻结不变

  ⚠️ 警告信号（Ctrl+C停止）：
    • 持续往复运动（振荡）
    • 多次冲过目标（超调）
    • 控制量始终为0（无响应）
    • R² < 0.6（辨识失败）
