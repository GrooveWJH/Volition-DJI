# 实验前快速检查清单

**打印此文档，实验前逐项确认打勾 ✓**

## 📋 硬件检查（5分钟）

- [ ] **无人机电池** ≥ 80%（显示在遥控器上）
- [ ] **螺旋桨** 紧固，无裂纹或损伤
- [ ] **IMU校准** 7天内完成（查看DJI Pilot App）
- [ ] **遥控器电量** 充足，信号强度满格
- [ ] **动捕标记点** 牢固，无松动或遮挡

## 🖥️ 软件检查（2分钟）

运行以下命令：

```bash
# 1. 验证依赖包
python control_mpc/verify_config.py

# 2. 检查航点安全性
python control_mpc/check_safety.py

# 3. 测试VRPN连接
python vrpn_test.py
```

**预期结果：**
- [ ] verify_config.py 显示 "✓ 所有配置正常"
- [ ] check_safety.py 显示 "✓ 所有航点均在安全范围内"
- [ ] vrpn_test.py 显示位置数据（更新率>90Hz）

## 🏟️ 场地检查（3分钟）

- [ ] **2m半径内** 无障碍物（桌子、椅子、设备等）
- [ ] **地面** 平整、无反光材料
- [ ] **光线** 充足均匀，无直射阳光
- [ ] **无气流** 关闭空调/风扇，门窗紧闭
- [ ] **边界标记** 已放置（1.5m和2.0m处）
- [ ] **安全警戒线** 已设置（3m半径）

## 👥 人员检查（2分钟）

- [ ] **飞手** 熟悉遥控器操作，能快速切换模式
- [ ] **安全员** 已就位，了解应急流程
- [ ] **沟通约定** 喊话口令已演练
  - "开始辨识" - 开始系统辨识阶段
  - "边界告警" - 无人机接近边界
  - "准备接管" - 异常情况，准备遥控器接管
  - "紧急降落" - 严重异常，立即降落

## 📱 通信检查（2分钟）

```bash
# 测试MQTT连接
mosquitto_pub -h 192.168.31.73 -t test -m "hello" -u dji -P lab605605

# 测试网络延迟
ping -c 10 192.168.31.73
ping -c 10 192.168.31.100
```

**预期结果：**
- [ ] MQTT命令成功（无错误提示）
- [ ] 网络延迟 < 10ms
- [ ] 无丢包

## 🔧 配置检查（关键！）

打开 `control/config.py`，确认以下参数：

- [ ] `WAYPOINTS` - 所有航点距离 < 1.5m
- [ ] `MAX_STICK_OUTPUT = 100` (或更小)
- [ ] `KP_XY = 300.0` (或更小)
- [ ] `PLANE_USE_RANDOM_WAYPOINTS = False`
- [ ] `PLANE_AUTO_NEXT_WAYPOINT = False`

打开 `control_mpc/system_id.py` 第54行，确认：

- [ ] `self.excitation_amplitude = 30.0` (不要超过40)

## 🚨 应急准备

- [ ] **遥控器** 已练习快速切换手动模式（<1秒）
- [ ] **降落点** 已清理，随时可降落
- [ ] **紧急联系人** 已通知实验时间和地点
- [ ] **急救包** 已备，位置已知

## 📝 实验记录准备

- [ ] 记录本/电子表格已准备
- [ ] 需记录内容：
  - 实验日期和时间
  - 参与人员
  - 系统辨识结果（R²值）
  - 航点到达时间
  - 任何异常现象
  - 数据文件路径
