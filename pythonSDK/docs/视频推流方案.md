# 视频推流方案

本方案以“云端集中转发 + 多终端可调阅”为核心思想，使用一台部署在云服务器上的 mediamtx 实例作为视频中枢。三架无人机的遥控器分别通过 5G 路由器接入互联网，将机载视频经加密 RTMP 推流到该 mediamtx 服务；IVAS 与无人机地面站（GCS）都可以在授权范围内从云端按需拉流，实现指挥端查看与地面站识别分析的“双用途”。

## 核心流程

1. **云端节点**：在云服务器（具有固定公网 IP/域名）上部署 mediamtx，开启 TLS/RTMPS 支持，并为每路视频配置独立的推流地址与访问凭据。  
2. **无人机侧推流**：每台无人机的遥控器通过 5G 路由器上网，按照预置的推流地址与密钥，将机载视频实时推送到 mediamtx。链路为 “遥控器 → 5G → 互联网 → mediamtx (RTMPS)”。  
3. **地面站拉流**：GCS 位于另一条 5G 接入链路上，同样通过加密 RTMP/RTSP/HLS 接口，从 mediamtx 拉取需要的视频通道，在本地执行 YOLOv8-VisDrone 等识别算法。  
4. **IVAS 观看**：IVAS 可在经过授权后通过内网/公网安全通道访问 mediamtx，对关键通道进行实时监看或录像回放，供指挥员掌握现场态势。  
5. **权限与安全**：推拉流均依赖 TLS 加密与账号/令牌认证，轻量配置即可满足基本安全要求；如需更高等级的防护，可进一步结合 VPN、IP 白名单或零信任代理。

该方案无需额外的转码或 CDN，即可满足“三机并行推流、多端按需拉流”的需求；后续若要扩展更多无人机或新增分析节点，只需在 mediamtx 中增配通道并分发新的访问凭据即可。
