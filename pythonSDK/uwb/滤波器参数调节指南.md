# UWB 滤波器参数调节指南

## 滤波器原理

`visualize_live.py` 使用 **双重滤波策略**：

1. **EMA (指数移动平均)** - 快速响应突变
2. **移动平均 (Moving Average)** - 平滑高频噪声

```python
# 滤波流程
原始数据 → EMA滤波 → 移动平均 → 最终输出
```

---

## 参数说明

### 1. `alpha` - EMA 滤波系数

**公式:**
```python
ema[i] = alpha × 原始值 + (1 - alpha) × ema[i-1]
```

**范围:** 0.0 ~ 1.0

**作用机制:**
- `alpha` 控制新数据的权重
- 越大 = 新数据权重越高 = 响应越快
- 越小 = 历史数据权重越高 = 越平滑

---

### 2. `window_size` - 移动平均窗口

**公式:**
```python
输出 = mean([最近N个EMA滤波后的数据])
```

**范围:** 1 ~ 50 (理论无上限)

**作用机制:**
- 对最近 N 个数据点求平均
- 窗口越大 = 平均的数据越多 = 越平滑

---

## 实际效果演示

### 场景 1: 噪声很大的静态测量

**问题:** 标签静止，但位置数据抖动 ±10cm

**推荐配置:**
```python
--alpha 0.1 --window 15
```

**效果:**
```
原始数据: [2.50, 2.58, 2.42, 2.55, 2.48, 2.51, ...]  (抖动 ±8cm)
滤波后:   [2.50, 2.51, 2.50, 2.51, 2.50, 2.50, ...]  (抖动 ±1cm)
```

**代价:** 延迟约 0.5 秒（如果采样频率 30Hz）

---

### 场景 2: 快速运动的标签跟踪

**问题:** 标签高速移动，需要实时跟踪，不能有太大延迟

**推荐配置:**
```python
--alpha 0.7 --window 3
```

**效果:**
```
原始数据: [2.50, 2.65, 2.80, 2.95, 3.10, ...]  (快速移动 + 噪声)
滤波后:   [2.50, 2.62, 2.78, 2.92, 3.08, ...]  (保留运动趋势，减少抖动)
```

**代价:** 仍有轻微噪声，但延迟很小（约 0.1 秒）

---

### 场景 3: 一般使用场景（默认）

**推荐配置:**
```python
--alpha 0.3 --window 5
```

**效果:** 平衡响应速度和平滑度，适合大多数应用

## 参数调节策略

### 🎯 调节流程图

```
开始
  ↓
数据抖动是否严重？
  ├─ 是 → 降低 alpha (0.1~0.3) + 增大 window (10~20)
  └─ 否 → 继续

  ├─ 是 → 提高 alpha (0.6~0.8) + 减小 window (2~5)

      ↓
观察效果，微调
```

## 数学原理详解

### EMA (指数移动平均)

**递推公式:**
```
S_0 = X_0
S_t = α × X_t + (1 - α) × S_{t-1}
```

**展开式:**
```
S_t = α × X_t + α(1-α) × X_{t-1} + α(1-α)² × X_{t-2} + ...
```

**特性:**
- 权重呈指数衰减
- 最近数据权重最大
- `α` 越小，衰减越慢，记忆越长

---

### 移动平均 (Simple Moving Average)

**公式:**
```
MA_t = (X_t + X_{t-1} + ... + X_{t-N+1}) / N
```

**特性:**
- 所有窗口内数据权重相等
- 窗口大小决定平滑强度
- 延迟 = N/2 × 采样周期

## 故障排查

### 问题 1: 滤波后数据仍然抖动很大

**原因:** 参数太激进，滤波强度不够

**解决方案:**
```bash
# 逐步降低 alpha
python uwb/visualize_live.py --alpha 0.2 --window 10

# 如果还抖动，继续降低
python uwb/visualize_live.py --alpha 0.1 --window 15
```

---

### 问题 2: 延迟太大，无法实时跟踪运动

**原因:** 滤波过强，平滑窗口太大

**解决方案:**
```bash
# 提高响应速度
python uwb/visualize_live.py --alpha 0.6 --window 3

# 如果延迟仍大，继续提高
python uwb/visualize_live.py --alpha 0.8 --window 2
```

---

### 问题 3: 滤波后曲线太"圆滑"，丢失真实细节

**原因:** `window_size` 过大导致过度平均

**解决方案:**
```bash
# 减小窗口，保留更多细节
python uwb/visualize_live.py --alpha 0.4 --window 3
```

## 总结

| 参数 | 作用 | 增大效果 | 减小效果 |
|------|------|---------|---------|
| **Alpha** | 控制新旧数据权重比 | 响应更快，更接近原始数据 | 更平滑，延迟更大 |
| **Window** | 控制平均的数据点数 | 更平滑，延迟更大 | 响应更快，保留更多细节 |

**核心原则:**
- **抖动大 → 降低 alpha + 增大 window**
- **延迟大 → 提高 alpha + 减小 window**
- **从默认值 (0.3, 5) 开始，逐步微调**
